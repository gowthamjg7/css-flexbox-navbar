# CSS Flexbox Navbar

A simple and responsive navigation bar created using HTML and CSS as part of my frontend development practice.

## Preview

A basic navigation layout featuring a logo, navigation links, and a login button.

## Features

- Logo positioned on the left
- Navigation links aligned horizontally
- Login button positioned on the right
- Flexbox layout using `display: flex`
- Spacing with `justify-content: space-between` and `gap`
- Vertically aligned elements using `align-items: center`
- Hover effects on navigation links and buttons

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
